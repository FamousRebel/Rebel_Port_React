# Rebel_Port - 个人网站

# 项目介绍

个人网站，基于 React + TypeScript + Vite 构建。

## 🎨 项目特点

- **现代化设计**: 使用 Tailwind CSS 4 和 shadcn/ui 组件库
- **流畅动画**: 基于 Framer Motion 的精美动画效果
- **状态管理**: 使用 Zustand 进行轻量级状态管理
- **响应式布局**: 完美适配各种屏幕尺寸 (暂未适配)
- **TypeScript**: 完整的类型支持

## 📁 项目结构

```
Frontend/
├── src/
│   ├── components/          # 组件目录
│   │   ├── Common/         # 通用组件
│   │   ├── Layout/         # 布局组件
│   │   ├── Sections/       # 页面区块
│   │   └── ui/            # UI 组件
│   ├── pages/              # 页面组件
│   ├── routes/             # 路由配置
│   ├── store/              # 状态管理
│   ├── types/              # TypeScript 类型定义
│   ├── lib/                # 工具函数
│   └── utils/              # 通用工具
├── public/                 # 静态资源
├── package.json            # 项目依赖
└── vite.config.ts          # Vite 配置
```

## 🚀 快速开始

### 安装依赖

```bash
cd Frontend
pnpm install
```

### 开发模式

```bash
pnpm dev
```

### 构建生产版本

```bash
pnpm build
```

### 预览生产版本

```bash
pnpm preview
```

### 代码检查

```bash
pnpm lint
```
